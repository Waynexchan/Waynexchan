# Featured Project

## UK Retail Analytics Dashboard

An end-to-end retail analytics project using transaction-level e-commerce data.

### Business Problem

The business needed a clearer understanding of revenue performance, customer purchasing behaviour, repeat orders, product performance and returns.

### Key Findings

- The UK generated approximately **91.5% of orders** and **85.6% of revenue**
- Non-UK average order value was approximately **£861**, compared with **£473** in the UK
- Approximately **22–23% of customers contributed around 80% of revenue**
- Gross sales and returns were separated to improve KPI accuracy

### What I Built

- Reusable SQL views for revenue, customers, products and returns
- Reporting-ready datasets in Google BigQuery
- Interactive Power BI dashboards
- DAX measures for commercial KPIs
- Customer segmentation and Pareto analysis
- Source-level validation checks to confirm dashboard accuracy

### Tools

**SQL · BigQuery · Power BI · Power Query · DAX**
